# Input & Field

Pill-shaped inputs with a green focus ring.

## Structure

- `sp-field` wraps `sp-field__label` + control.
- `sp-input` — the control (pill). Focus = green border + soft green glow.
- Pair with a `sp-btn--icon` for search/submit rows.

## In the app (DaisyUI)

Maps to `input input-bordered`; the composer row uses a rounded input + `btn-primary`.
