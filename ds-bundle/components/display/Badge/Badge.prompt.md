# Badge

Pill status labels for sync state, tags, and feature flags.

## Classes

- `sp-badge` base. Tone: `sp-badge--green` (synced/success), `sp-badge--violet` (**AI / Vibes**), `sp-badge--gold` (new/highlight), `sp-badge--danger` (failed), `sp-badge--neutral` (quiet), `sp-badge--soft` (green-tinted count/meta).

## Rules

- `--violet` marks AI-generated content (mixtapes, recommendations). `--green` marks healthy sync state.

## In the app (DaisyUI)

Maps to `badge badge-primary` (green), `badge badge-secondary` (violet), `badge badge-accent` (gold), `badge badge-error`.
